# Question 3: Average with a NULL Value

**Topics:** NULL, Aggregate Functions, AVG

## 📝 Question

> What is the average of the values 10, 20, NULL and 30?

## 🔢 Options

**Option 1:** 20

**Option 2:** 15

**Option 3:** 10

**Option 4:** NULL

## 💡 About this question

In SQL and most analytical tools, **aggregate functions (such as AVG and SUM) ignore NULL values**; NULL is neither counted as zero nor included in the denominator.

So the average is computed only over the three non-NULL values: `(10 + 20 + 30) / 3 = 60 / 3 = 20`.

## 🔍 Detailed review of every option

### Option 1 — ✅ Correct

> 20

**Correct.** NULL is ignored by AVG, and the average of the three existing values is `(10+20+30)/3 = 20`.

### Option 2 — ❌ Incorrect

> 15

**Incorrect.** 15 results when NULL is treated as "zero" and divided by 4: `(10+20+0+30)/4 = 15`. But NULL means "unknown," and AVG does not count it as zero.

### Option 3 — ❌ Incorrect

> 10

**Incorrect.** 10 does not result from any standard way of computing the average (it could only resemble the first value or the minimum). The average of the three existing values is 20.

### Option 4 — ❌ Incorrect

> NULL

**Incorrect.** NULL turns the result into NULL only in direct arithmetic expressions such as `10 + 20 + NULL + 30`. The AVG aggregate skips NULL values and does not return NULL (unless all values are NULL).

## ✅ Correct answer

**Option 1**

> 20

## 🎯 Why it is correct

AVG works on non-NULL values: a sum of 60 divided by 3 values = 20.

## 📌 Key takeaway

NULL = “unknown,” not zero. Aggregate functions skip it.
