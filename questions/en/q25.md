# Question 25: ELT vs ETL

**Topics:** ETL, ELT, Cloud Data Warehouse, Data Processing

## 📝 Question

> What is the difference between ELT and ETL?

## 🔢 Options

**Option 1:** In ELT no transformation is performed on the data

**Option 2:** ELT has no extraction step

**Option 3:** ETL is used only for real-time data

**Option 4:** In ELT the data is first loaded into the destination and then transformed using the destination's processing power

## 💡 About this question

The order of the steps is the main difference:

- **ETL:** Extract → **Transform** (on a server/intermediate tool) → Load.
- **ELT:** Extract → **Load** (raw data into the destination) → **Transform** (using the destination's processing power, such as a cloud data warehouse).

ELT is common for powerful, scalable destinations and also keeps the raw data.

## 🔍 Detailed review of every option

### Option 1 — ❌ Incorrect

> In ELT no transformation is performed on the data

**Incorrect.** ELT also performs transformation; it just happens **after** loading, inside the destination.

### Option 2 — ❌ Incorrect

> ELT has no extraction step

**Incorrect.** The E in ELT stands for Extract; the extraction step exists in ELT too.

### Option 3 — ❌ Incorrect

> ETL is used only for real-time data

**Incorrect.** ETL is not limited to real-time data; it is in fact very common for batch processing as well.

### Option 4 — ✅ Correct

> In ELT the data is first loaded into the destination and then transformed using the destination's processing power

**Correct.** In ELT the data is first loaded into the destination and then transformed using the destination's processing power.

## ✅ Correct answer

**Option 4**

> In ELT the data is first loaded into the destination and then transformed using the destination's processing power

## 🎯 Why it is correct

The difference lies in where the transform step happens: in ELT, after loading and inside the destination itself.

## 📌 Key takeaway

ETL: transform before loading. ELT: transform after loading (in the destination).
