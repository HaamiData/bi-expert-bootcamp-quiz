# Question 11: Running Total with a Window Function

**Topics:** SQL, Window Functions, OVER, Running Total

## 📝 Question

> Which expression is appropriate for calculating the cumulative (running) total of sales by date?

## 🔢 Options

**Option 1:** `() COUNT(amount) OVER`

**Option 2:** `SUM(amount) GROUP BY order_date`

**Option 3:** `SUM(amount) OVER (ORDER BY order_date)`

**Option 4:** `RANK() OVER (ORDER BY amount)`

## 💡 About this question

A **window function** performs a calculation over a "window of rows" without collapsing the rows the way GROUP BY does.

When `ORDER BY` appears inside `OVER`, the default window runs from the **first row to the current row**; so `SUM(amount) OVER (ORDER BY order_date)` gives, in each row, the total sales from the beginning up to that date, i.e. a **running total**.

## 🔍 Detailed review of every option

### Option 1 — ❌ Incorrect

> `() COUNT(amount) OVER`

**Incorrect.** The syntax of this expression is not valid (the position of `OVER` and the parentheses is wrong). Even if written correctly (`COUNT(amount) OVER ()`), `COUNT` counts rows; it does not produce a running total of amounts.

### Option 2 — ❌ Incorrect

> `SUM(amount) GROUP BY order_date`

**Incorrect.** `SUM ... GROUP BY order_date` gives the total sales of **each day on its own** (one row per date), not a running total that includes earlier days.

### Option 3 — ✅ Correct

> `SUM(amount) OVER (ORDER BY order_date)`

**Correct.** The `SUM` aggregate with `OVER (ORDER BY order_date)` accumulates in date order from the beginning to the current row. (Note: if several rows share the same date, the default `RANGE` window gives them the same running value; for row-by-row accumulation use `ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW`.)

### Option 4 — ❌ Incorrect

> `RANK() OVER (ORDER BY amount)`

**Incorrect.** `RANK()` gives the row's rank based on `amount`; it is not a running total of sales by date.

## ✅ Correct answer

**Option 3**

> `SUM(amount) OVER (ORDER BY order_date)`

## 🎯 Why it is correct

Running total = `SUM` as a window function with `ORDER BY` on the date.

## 📌 Key takeaway

`SUM(x) OVER (ORDER BY date)` = running total; `GROUP BY` collapses rows while a window function does not.
