# Question 14: The Star Schema Model

**Topics:** Dimensional Modeling, Star Schema, Fact, Dimension

## 📝 Question

> What is the Star Schema model?

## 🔢 Options

**Option 1:** A set of tables with no specific relationship

**Option 2:** A central Fact table connected to several Dimension tables

**Option 3:** Only Dimension tables without a Fact

**Option 4:** A single table in which all the data is placed

## 💡 About this question

**Star Schema** is the most common dimensional-modeling pattern: a **Fact** table sits in the center and **Dimension** tables, like the rays of a star, connect to it through keys. The structure is simple, fast for analytical queries and well suited to Power BI.

## 🔍 Detailed review of every option

### Option 1 — ❌ Incorrect

> A set of tables with no specific relationship

**Incorrect.** In a Star Schema the relationships are well defined (dimension primary key → fact foreign key). Tables with no relationships are not a star model.

### Option 2 — ✅ Correct

> A central Fact table connected to several Dimension tables

**Correct.** That is the definition of a Star Schema: a central Fact connected to several Dimensions.

### Option 3 — ❌ Incorrect

> Only Dimension tables without a Fact

**Incorrect.** Without a Fact table there are no events/measures to analyze; Fact is the center of the star.

### Option 4 — ❌ Incorrect

> A single table in which all the data is placed

**Incorrect.** A single table holding all data is a flat model (one big table), not a Star Schema.

## ✅ Correct answer

**Option 2**

> A central Fact table connected to several Dimension tables

## 🎯 Why it is correct

Star Schema = one central Fact + several Dimensions connected to it.

## 📌 Key takeaway

Star: Fact in the center, Dimensions around it.
