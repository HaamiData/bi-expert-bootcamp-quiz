# Question 13: Purpose of GROUP BY

**Topics:** SQL, GROUP BY, Aggregation

## 📝 Question

> In an SQL query, what is the main role of GROUP BY?

## 🔢 Options

**Option 1:** Grouping rows based on the shared values of one or more columns

**Option 2:** Final sorting of rows based on the value of a column

**Option 3:** Removing duplicate records from the source table

**Option 4:** Joining the rows of two tables based on a foreign key

## 💡 About this question

`GROUP BY` places rows that have the same value in the specified column(s) into one **group** so that an aggregate function (`SUM`, `COUNT`, `AVG`...) can run on each group. Example: total sales by region.

## 🔍 Detailed review of every option

### Option 1 — ✅ Correct

> Grouping rows based on the shared values of one or more columns

**Correct.** The main job of GROUP BY is to group rows by the shared values of one or more columns, usually for aggregation.

### Option 2 — ❌ Incorrect

> Final sorting of rows based on the value of a column

**Incorrect.** Sorting is the job of `ORDER BY`. (In some engines the output of `GROUP BY` may appear ordered, but that is neither guaranteed nor its purpose.)

### Option 3 — ❌ Incorrect

> Removing duplicate records from the source table

**Incorrect.** Removing duplicates is the job of `DISTINCT`. Although GROUP BY can give a result resembling duplicate removal, its main purpose is grouping for aggregation.

### Option 4 — ❌ Incorrect

> Joining the rows of two tables based on a foreign key

**Incorrect.** Linking rows of two tables is the job of `JOIN` (based on a foreign key/join condition), not GROUP BY.

## ✅ Correct answer

**Option 1**

> Grouping rows based on the shared values of one or more columns

## 🎯 Why it is correct

GROUP BY = grouping by shared column values; the other jobs belong to ORDER BY, DISTINCT and JOIN.

## 📌 Key takeaway

GROUP BY groups, ORDER BY sorts, DISTINCT removes duplicates, JOIN connects.
