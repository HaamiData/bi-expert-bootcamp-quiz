# Question 22: OLTP vs OLAP

**Topics:** OLTP, OLAP, Data Warehouse, Transactional Databases

## 📝 Question

> What is the main difference between OLTP and OLAP systems?

## 🔢 Options

**Option 1:** OLAP runs only on NoSQL databases

**Option 2:** All options are correct

**Option 3:** OLTP is designed for analyzing historical data and OLAP for recording transactions

**Option 4:** OLTP is optimized for short/high-volume transactions and OLAP for analytical queries over large volumes of data

## 💡 About this question

- **OLTP (Online Transaction Processing):** day-to-day recording and updating of data (orders, payments...). **Short, high-volume** transactions, high normalization, row-based storage.
- **OLAP (Online Analytical Processing):** analysis of **large volumes of historical data** with heavy, aggregating queries. Usually a data warehouse, dimensional model, columnar storage.

## 🔍 Detailed review of every option

### Option 1 — ❌ Incorrect

> OLAP runs only on NoSQL databases

**Incorrect.** OLAP is not limited to a database type; it usually runs on relational/columnar warehouses, cubes, etc., and is not restricted to NoSQL.

### Option 2 — ❌ Incorrect

> All options are correct

**Incorrect.** Options 1 and 3 are false, so "all options are correct" is wrong.

### Option 3 — ❌ Incorrect

> OLTP is designed for analyzing historical data and OLAP for recording transactions

**Incorrect.** This option states the roles **backwards**: OLTP is designed for recording transactions and OLAP for analyzing historical data.

### Option 4 — ✅ Correct

> OLTP is optimized for short/high-volume transactions and OLAP for analytical queries over large volumes of data

**Correct.** OLTP is optimized for short, high-volume transactions and OLAP for analytical queries over large volumes of data.

## ✅ Correct answer

**Option 4**

> OLTP is optimized for short/high-volume transactions and OLAP for analytical queries over large volumes of data

## 🎯 Why it is correct

OLTP = transaction recording (short, high-volume); OLAP = analysis of large data volumes.

## 📌 Key takeaway

OLTP: record. OLAP: analyze.
