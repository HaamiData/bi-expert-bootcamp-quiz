# Question 4: COUNT(X) and NULL Values

**Topics:** COUNT, NULL, SQL

## 📝 Question

> In a table with 100 rows, if column X has 20 NULL values, what is the result of COUNT(X)?

## 🔢 Options

**Option 1:** 20

**Option 2:** 80

**Option 3:** 100

**Option 4:** 120

## 💡 About this question

An important difference in SQL:

- `COUNT(*)` counts all **rows** (NULL or not).
- `COUNT(X)` counts only the rows where column X is **not NULL**.

So `COUNT(X) = 100 − 20 = 80`.

## 🔍 Detailed review of every option

### Option 1 — ❌ Incorrect

> 20

**Incorrect.** 20 is the number of NULL values, not the result of COUNT(X). COUNT(X) does not count NULLs.

### Option 2 — ✅ Correct

> 80

**Correct.** Of the 100 rows, 20 have NULL and 80 have a non-null value; `COUNT(X)` returns those 80.

### Option 3 — ❌ Incorrect

> 100

**Incorrect.** 100 is the result of `COUNT(*)` (counting all rows), not `COUNT(X)`.

### Option 4 — ❌ Incorrect

> 120

**Incorrect.** 120 is more than the total number of rows, and a count can never exceed the number of rows.

## ✅ Correct answer

**Option 2**

> 80

## 🎯 Why it is correct

COUNT(column) counts only non-NULL values: `100 − 20 = 80`.

## 📌 Key takeaway

`COUNT(*)` counts all rows; `COUNT(column)` counts only non-NULL values.
