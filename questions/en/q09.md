# Question 9: The Role of CALCULATE in DAX

**Topics:** DAX, Power BI, Filter Context, CALCULATE

## 📝 Question

> What role does the CALCULATE function have in DAX?

## 🔢 Options

**Option 1:** Loads data from the source

**Option 2:** Only calculates the sum of columns

**Option 3:** Creates the relationship between tables

**Option 4:** Changes the calculation context

## 💡 About this question

In DAX the result of any measure depends on the **context** (especially filter context): the filters applied to the calculation by slicers, table/chart rows and columns, and model relationships.

`CALCULATE(<expression>, <filter1>, ...)` evaluates an expression in a **modified** context; that is, it can add, replace or remove filters. Example:

```
Sales 2024 = CALCULATE( SUM(Sales[Amount]), Sales[Year] = 2024 )
```

## 🔍 Detailed review of every option

### Option 1 — ❌ Incorrect

> Loads data from the source

**Incorrect.** Loading data from a source is the job of Power Query (and data sources), not DAX functions.

### Option 2 — ❌ Incorrect

> Only calculates the sum of columns

**Incorrect.** Summing columns is the job of `SUM`. CALCULATE is more general: it evaluates any expression (not just sums) in a modified context.

### Option 3 — ❌ Incorrect

> Creates the relationship between tables

**Incorrect.** Relationships between tables are defined in the model (Model view). (`USERELATIONSHIP` can activate an inactive relationship inside CALCULATE, but CALCULATE itself does not create relationships.)

### Option 4 — ✅ Correct

> Changes the calculation context

**Correct.** CALCULATE changes the filter context and evaluates the expression in that new context; that is why it is the most widely used and most important DAX function.

## ✅ Correct answer

**Option 4**

> Changes the calculation context

## 🎯 Why it is correct

CALCULATE evaluates an expression in a manipulated context (adding/replacing/removing filters).

## 📌 Key takeaway

CALCULATE = evaluating an expression in a modified filter context.
