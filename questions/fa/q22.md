# سوال ۲۲: OLTP در برابر OLAP

**موضوع‌ها:** OLTP، OLAP، انبار داده، پایگاه‌داده تراکنشی

## 📝 متن سوال

> تفاوت اصلی سیستم‌های OLTP و OLAP کدام است؟

## 🔢 گزینه‌ها

**گزینه ۱:** OLAP فقط روی پایگاه‌داده‌های NoSQL اجرا می‌شود

**گزینه ۲:** همه گزینه‌ها صحیح می‌باشد

**گزینه ۳:** OLTP برای تحلیل داده‌های تاریخی و OLAP برای ثبت تراکنش‌ها طراحی شده است

**گزینه ۴:** OLTP برای تراکنش‌های کوتاه/پرتعداد و OLAP برای کوئری‌های تحلیلی روی حجم زیاد داده بهینه شده است

## 💡 توضیح سوال

- **OLTP (پردازش تراکنشی برخط):** ثبت و به‌روزرسانی روزمره‌ی داده (سفارش، پرداخت ...). تراکنش‌های **کوتاه و پرتعداد**، نرمال‌سازی بالا، ذخیره‌سازی ردیفی.
- **OLAP (پردازش تحلیلی برخط):** تحلیل **حجم زیاد داده‌ی تاریخی** با کوئری‌های سنگین و تجمیعی. معمولاً انبار داده، مدل ابعادی، ذخیره‌سازی ستونی.

## 🔍 بررسی کامل هر گزینه

### گزینه ۱ — ❌ نادرست

> OLAP فقط روی پایگاه‌داده‌های NoSQL اجرا می‌شود

**نادرست.** OLAP به نوع پایگاه‌داده محدود نیست؛ معمولاً روی انبار داده‌های رابطه‌ای/ستونی، مکعب‌ها و ... اجرا می‌شود و محدود به NoSQL نیست.

### گزینه ۲ — ❌ نادرست

> همه گزینه‌ها صحیح می‌باشد

**نادرست.** گزینه‌های ۱ و ۳ غلط‌اند، پس «همه صحیح است» نادرست است.

### گزینه ۳ — ❌ نادرست

> OLTP برای تحلیل داده‌های تاریخی و OLAP برای ثبت تراکنش‌ها طراحی شده است

**نادرست.** این گزینه نقش‌ها را **برعکس** گفته است: OLTP برای ثبت تراکنش و OLAP برای تحلیل داده‌ی تاریخی طراحی شده است.

### گزینه ۴ — ✅ صحیح

> OLTP برای تراکنش‌های کوتاه/پرتعداد و OLAP برای کوئری‌های تحلیلی روی حجم زیاد داده بهینه شده است

**درست.** OLTP برای تراکنش‌های کوتاه و پرتعداد و OLAP برای کوئری‌های تحلیلی روی حجم زیاد داده بهینه است.

## ✅ گزینه صحیح

**گزینه ۴**

> OLTP برای تراکنش‌های کوتاه/پرتعداد و OLAP برای کوئری‌های تحلیلی روی حجم زیاد داده بهینه شده است

## 🎯 علت درست بودن

OLTP = ثبت تراکنش (کوتاه و پرتعداد)؛ OLAP = تحلیل حجم زیاد داده.

## 📌 نکته کلیدی

OLTP: ثبت. OLAP: تحلیل.
