# سوال ۳: میانگین با مقدار NULL

**موضوع‌ها:** NULL، توابع تجمیعی، AVG

## 📝 متن سوال

> میانگین مقادیر 10، 20، NULL و 30 چقدر است؟

## 🔢 گزینه‌ها

**گزینه ۱:** 20

**گزینه ۲:** 15

**گزینه ۳:** 10

**گزینه ۴:** NULL

## 💡 توضیح سوال

در SQL و بیشتر ابزارهای تحلیلی، **توابع تجمیعی (مثل AVG و SUM) مقادیر NULL را نادیده می‌گیرند**؛ یعنی NULL نه صفر حساب می‌شود و نه در مخرج می‌آید.

پس میانگین فقط روی سه مقدار غیر‌NULL محاسبه می‌شود: `(10 + 20 + 30) / 3 = 60 / 3 = 20`.

## 🔍 بررسی کامل هر گزینه

### گزینه ۱ — ✅ صحیح

> 20

**درست.** NULL در AVG نادیده گرفته می‌شود و میانگین سه مقدار موجود `(10+20+30)/3 = 20` است.

### گزینه ۲ — ❌ نادرست

> 15

**نادرست.** عدد ۱۵ زمانی به دست می‌آید که NULL را «صفر» فرض کنیم و بر ۴ تقسیم کنیم: `(10+20+0+30)/4 = 15`. اما NULL به معنی «نامشخص» است و AVG آن را صفر حساب نمی‌کند.

### گزینه ۳ — ❌ نادرست

> 10

**نادرست.** ۱۰ با هیچ روش استاندارد محاسبه میانگین به دست نمی‌آید (تنها می‌تواند شبیه مقدار اول یا کمینه باشد). میانگین سه مقدار موجود ۲۰ است.

### گزینه ۴ — ❌ نادرست

> NULL

**نادرست.** NULL فقط در عبارت‌های حسابی مستقیم مثل `10 + 20 + NULL + 30` نتیجه را NULL می‌کند. اما تابع تجمیعی AVG مقدار NULL را کنار می‌گذارد و نتیجه NULL نمی‌شود (مگر همه مقادیر NULL باشند).

## ✅ گزینه صحیح

**گزینه ۱**

> 20

## 🎯 علت درست بودن

AVG روی مقادیر غیر‌NULL کار می‌کند: مجموع ۶۰ تقسیم بر ۳ مقدار = ۲۰.

## 📌 نکته کلیدی

NULL = «نامشخص»، نه صفر. توابع تجمیعی آن را نادیده می‌گیرند.
