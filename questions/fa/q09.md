# سوال ۹: نقش تابع CALCULATE در DAX

**موضوع‌ها:** DAX، Power BI، Filter Context، CALCULATE

## 📝 متن سوال

> تابع CALCULATE در DAX چه نقشی دارد؟

## 🔢 گزینه‌ها

**گزینه ۱:** داده‌ها را از منبع بارگذاری می‌کند

**گزینه ۲:** فقط جمع ستون‌ها را حساب می‌کند

**گزینه ۳:** رابطه بین جداول را ایجاد می‌کند

**گزینه ۴:** Context محاسبه را تغییر می‌دهد

## 💡 توضیح سوال

در DAX نتیجه‌ی هر Measure به **Context** (به‌ویژه Filter Context) بستگی دارد: فیلترهایی که از اسلایسرها، سطرها/ستون‌های جدول و نمودار و روابط مدل روی محاسبه اعمال می‌شوند.

`CALCULATE(<عبارت>, <فیلتر۱>, ...)` یک عبارت را در یک Context **تغییریافته** ارزیابی می‌کند؛ یعنی می‌تواند فیلترها را اضافه، جایگزین یا حذف کند. مثال:

```
Sales 2024 = CALCULATE( SUM(Sales[Amount]), Sales[Year] = 2024 )
```

## 🔍 بررسی کامل هر گزینه

### گزینه ۱ — ❌ نادرست

> داده‌ها را از منبع بارگذاری می‌کند

**نادرست.** بارگذاری داده از منبع کار Power Query (و منابع داده) است، نه توابع DAX.

### گزینه ۲ — ❌ نادرست

> فقط جمع ستون‌ها را حساب می‌کند

**نادرست.** جمع ستون‌ها کار `SUM` است. CALCULATE عمومی‌تر است: هر عبارتی (نه فقط جمع) را در Context تغییریافته ارزیابی می‌کند.

### گزینه ۳ — ❌ نادرست

> رابطه بین جداول را ایجاد می‌کند

**نادرست.** رابطه بین جداول در مدل (Model view) تعریف می‌شود. (تابع `USERELATIONSHIP` می‌تواند در CALCULATE یک رابطه‌ی غیرفعال را فعال کند، اما خود CALCULATE رابطه نمی‌سازد.)

### گزینه ۴ — ✅ صحیح

> Context محاسبه را تغییر می‌دهد

**درست.** CALCULATE Filter Context را تغییر می‌دهد و عبارت را در آن Context جدید ارزیابی می‌کند؛ به همین دلیل پرکاربردترین و مهم‌ترین تابع DAX است.

## ✅ گزینه صحیح

**گزینه ۴**

> Context محاسبه را تغییر می‌دهد

## 🎯 علت درست بودن

CALCULATE عبارت را در Context دست‌کاری‌شده ارزیابی می‌کند (افزودن/جایگزینی/حذف فیلتر).

## 📌 نکته کلیدی

CALCULATE = ارزیابی یک عبارت در Filter Context تغییریافته.
